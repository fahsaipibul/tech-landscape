    Save to GitHub

    Edits are saved by committing data/landscape.json to your repo. You only set this up once per browser. Your token stays in this browser and is only sent to GitHub.

    How do I get a token?
    1. Go to GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Name it "tech-landscape", set an expiration you're comfortable with.
    3. Repository access: Only select repositories → pick this repo.
    4. Permissions → Repository → Contents: Read and write. Nothing else.
    5. Generate, copy, and paste it above.
